# Промпт: «Помощь на дороге» — мастер, СТО, эвакуатор рядом, и без интернета

Вставить в Claude Code в проекте фронта «Кудайберген» (Expo, expo-router, TanStack Query, Zustand) целиком.
Контракт API — `BACKEND_SPEC.md`, раздел 16 (и Swagger, тег «Помощь на дороге»).

---

## Зачем

Человек сломался в дороге — нужен ближайший мастер, шиномонтаж или эвакуатор **сейчас**. Заявка с ожиданием
откликов (раздел 12) здесь вторична: сначала — список ближайших с большой кнопкой «Позвонить».

И главное: на трассе Бишкек–Ош (Тоо-Ашуу, Ала-Бель, Суусамыр, Кара-Балта–Чычкан) мобильного интернета часто нет.
Там всё равно работают **GPS** (спутники, без сети), **звонок** и **SMS**. Поэтому справочник мастеров заранее лежит
на телефоне, а «кто ближе» приложение считает само.

## 1. Вход — кнопка «Сломался — нужна помощь»

- Красная/акцентная кнопка на главной и в табе услуг, доступна в один тап. Только для вошедших (бэкенд требует
  токен); гостю — экран входа, а под ним всё равно экстренные номера (п. 6).
- Тап → сразу экран «Кто рядом». Ничего не спрашивать до показа списка: машина, описание, фото — потом и по желанию.

## 2. Экран «Кто рядом»

- Чипсы услуг сверху: **Эвакуатор** (по умолчанию), Выездной мастер, Шиномонтаж, СТО, Автоэлектрик, «Все».
- Карточка: имя, `★ rating · reviewsCount`, **«85 км от вас»**, услуги, метка «Доедет к вам», если `reachesYou`,
  и «Не ваша марка» приглушённо, если `worksWithCar === false`. Кнопки: **Позвонить** (большая), **SMS**, «Маршрут»
  (2GIS/Яндекс по `lat/lng`), «Профиль».
- Расстояние: до 1 км — «850 м», до 10 км — «1,2 км», дальше — целыми «85 км».
- Внизу — «Не дозвонились? Отправить заявку всем рядом» → существующий поток `POST /service-requests`
  (у эвакуатора радиус до 200 км, ползунок — до `service.maxRadiusKm`).

### Откуда данные

| Сеть есть | `GET /roadside/nearby?lat&lng&service&carId` — свежо, с аватарами и рейтингом |
|---|---|
| Сети нет / запрос не ответил за 4 с | локальный справочник (п. 3), расчёт на телефоне (п. 4) |

Плашка в офлайне: «Нет интернета — показаны сохранённые мастера (обновлено 14 ноября, 09:12)». Переключение —
по `@react-native-community/netinfo` **и** по таймауту запроса: «есть сеть» в горах часто значит «EDGE на 1 палке».

## 3. Справочник на телефоне

- `GET /roadside/offline-pack` — все действующие мастера страны (сотни записей, ~20 КБ в gzip).
- Хранить файлом (`expo-file-system`, `documentDirectory/roadside-pack.json`) или в `expo-sqlite` — **не** в кеше
  TanStack Query (его сбрасывает logout/обновление). Отдельно — `version` и время скачивания.
- Когда обновлять:
  - сразу после входа;
  - при запуске: `GET /roadside/offline-pack/version`, версия другая — скачать пакет;
  - раз в сутки в фоне (`expo-background-task`), если есть сеть;
  - всегда с `If-None-Match: "<version>"` → 304 = ничего не делать. 429 `PACK_RATE_LIMITED` — тихо пропустить.
- Справочнику больше 3 дней — в «Кто рядом» мягкий баннер «Перед дальней дорогой обновите справочник» с кнопкой.
- Logout справочник **не** стирает (данные не личные); удаление аккаунта — стирает.

## 4. Расчёт без сети

- Точка: `expo-location` — сначала `getLastKnownPositionAsync` (мгновенно), параллельно
  `getCurrentPositionAsync({accuracy: Balanced})` с таймаутом ~10 с; новый фикс — пересортировать список.
  GPS без интернета ловит дольше (нет A-GPS) — показывать «Ищем вас по GPS…» поверх списка по последней точке.
- Расстояние — гаверсинус (как `Distances.meters` на бэкенде), R = 6 371 000 м.
- Фильтр: `services` содержит выбранную услугу; свой профиль мастера не показывать.
- `reachesYou = distance ≤ radiusKm * 1000`; `worksWithCar` — как `Master.worksWith`: `allBrands ||
  brandIds.includes(brandId)` и (`origins` пусто || страна машины неизвестна || `origins.includes(origin)`).
  Машина — текущая из гаража (он тоже должен лежать локально).
- Порядок: сначала «доедет и берётся за машину», потом остальные; внутри — по расстоянию. Первые 30.
- Совсем нет точки (GPS выключен) — список по алфавиту с подсказкой «Включите геолокацию», чипсы работают.

## 5. Позвонить и SMS — работают без интернета

- Звонок: `Linking.openURL('tel:' + phone)`.
- SMS: `expo-sms` (`SMS.sendSMSAsync([phone], text)`), запасной — `sms:` URL (на iOS `&body=`, на Android `?body=`).
- Текст SMS собирается на телефоне, по-русски или по-кыргызски по языку:
  ```
  Здравствуйте! Нашёл вас в «Кудайберген». Сломалась машина: Toyota Camry 2012.
  Нужен эвакуатор. Я здесь: 42.33512, 73.80731 (точность 30 м, 14:05)
  https://2gis.kg/geo/73.80731,42.33512
  ```
  Координаты — 5 знаков, ссылка откроется у мастера, когда у него будет сеть. Перед отправкой — дать дописать.
- Кнопка «Скопировать мои координаты» — для звонка («продиктуйте мастеру»).

## 6. Экстренные номера

Всегда видны внизу экрана «Кто рядом», даже при пустом справочнике и без входа: из `emergency` пакета, а до первого
скачивания — зашитые в приложение **112** (единая служба спасения), **103** (скорая), **102** (милиция),
**101** (пожарная).

## 7. Заявка без сети — в очередь

- Если пользователь всё же оформил заявку (`POST /service-requests`) без сети — сохранить в очередь (Zustand
  persist) с заранее созданным `Idempotency-Key` и `locatedAt` = время GPS-фикса. Отправить, когда появится сеть
  (NetInfo), повторы — с тем же ключом. Фото/голос — загрузить перед заявкой, при неудаче — отправить без них.
- В «Моих заявках» — карточка «Ждёт сети · отправится автоматически» с кнопкой «Отменить».
- Мастеру бэкенд сам покажет «точка от 14:05», если между `locatedAt` и отправкой больше 30 мин.

## 8. Мастер (профиль, экран 38)

- Телефон обязателен: при регистрации подставлен номер аккаунта, очистить нельзя (400 `PHONE_REQUIRED`). Подпись:
  «По этому номеру вам позвонят с трассы, где нет интернета».
- Радиус: ползунок до 30 км; если среди услуг эвакуатор или выездной мастер — до 200 км (макс. `maxRadiusKm` из
  `GET /service-types` среди дальних услуг). 400 `RADIUS_TOO_LARGE` — показать `message`.
- В ленте заявок (`GET /my/master/requests`) поле `locatedAt` ≠ null — плашка «Клиент был без сети, точка от 14:05».

## Проверка

- Режим полёта + включённый GPS: «Кто рядом» открывается, сортировка по расстоянию, звонок и SMS-композер
  открываются.
- Симулятор: подставить точку перевала Тоо-Ашуу (42.335, 73.807) — в списке эвакуаторы Бишкека/Сосновки за десятки км.
- Повторный запуск без изменений на бэкенде — `/offline-pack` отвечает 304, файл не переписывается.
- Заявка в режиме полёта → выключить режим → уходит одна (тот же Idempotency-Key).
